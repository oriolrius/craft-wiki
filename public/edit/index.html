Senior Contributors

Use Discord

For members with the Senior Contributor role.

  1. Choose Sign In Using Discord in the visual editor.
  2. Edit a guide and save. Your changes save directly to the wiki.

No GitHub account or token needed.

All other contributors & maintainers

Use a GitHub token

  1. Create a token for your access level using the details below.
  2. Choose Sign In Using GitHub Access Token in the visual editor and paste your token.
  3. If you don’t have write access, accept the prompt to create or reuse your fork.
  4. Save your changes, then choose Send for Review to open a pull request. Maintainers with write access save directly to main.
Community contributors: token setup

Without repository write access, create a classic token with public_repo access.

Scope: this covers all public repositories your account can access, including your fork. It cannot be restricted to this repository.

Maintainers: token setup

With repository write access, use a fine-grained token limited to storytold/craft-wiki, with Contents: Read and write.

You may need organization approval for a fine-grained token.

Contributions sent for review go live after a maintainer merges them. Updates deploy from main.
